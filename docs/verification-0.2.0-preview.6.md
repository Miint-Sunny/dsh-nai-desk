## 实际界面

在隔离 DSH_HOME 的真实 Web 宿主中，用本地假模型（只回固定的工具调用，不连外网）验证：

- 新建 NAI5 会话，右侧栏收起；发送消息后模型写稿，右侧栏推开并停在稿纸页，标记为本会话已自动打开过。
- 每轮写过稿的回复末尾出现「提示词稿纸 · 已写入 主提示词、角色 1、UC · 打开」卡片，外观与方案卡片一致。
- 主提示词中选中「café」后点「向模型屏蔽」：文本变为 `⟪屏蔽1⟫` 并画成灰条，灰条与文字对齐；复制整段得到原文；光标停在占位旁显示原文和「取消屏蔽」；随后让模型读稿，模型读到的是 `⟪屏蔽1⟫`。
- 角色提示词中的占位按一次退格整段删除；整个角色屏蔽后卡头显示「模型看不到」。
- 历史：「‹」翻到上一步时内容只读、提示条显示来源和改动；「用这一版」恢复后新增一步「恢复较早版本」。
- 深色、浅色主题下卡片为输入框同款玻璃描边；约 360px 宽的面板中标题栏和角色操作区正常换行。
