## 实际界面

在隔离 DSH_HOME 的真实 Web 宿主中，用本地假模型（只回固定的工具调用，不连外网）验证：

- 未屏蔽的主提示词显示睁眼，整个角色屏蔽后显示闭眼并带按下底色；没有文字标签。屏蔽 UC 后，切回主提示词页签时「UC」页签仍带闭眼标记，可访问名称为「UC（模型不可见）」。
- 「角色 1」小标题已删除，主提示词卡和角色组之间为 24px，角色卡之间为 12px。
- 「⋯」菜单：指针打开时焦点留在按钮上，Escape 关闭并回到按钮；键盘打开时焦点落在第一个可用项，↓ 跳过不可用的「下移」到「删除」；删除后焦点移到「撤销」，撤销后角色恢复。
- 版本历史：翻到较早版本时提示条只显示来源、时间和改动，按钮为「返回当前版本」「恢复此版本」；屏蔽和启停按原状态显示且不可操作，菜单隐藏；屏幕阅读器区域播报「正在查看第 3 个版本，共 4 个」。
- 选中文字后提示行为「已选 6 个字符」和「向模型屏蔽」；光标停在占位旁时完整显示原文和「取消屏蔽」。
- 全栏编辑按钮切换为「退出全栏编辑」和向内的图形，角色组隐藏。
- 回复末尾卡片为「稿纸 · 已修改：主提示词、角色 1、UC · 打开」，可访问名称「在侧边栏打开稿纸」。
- 深色、浅色主题正常；面板宽 360px 和 320px 时没有横向溢出，角色标题栏保持一行，菜单完整显示。

测试内容为合成示例，没有调用真实模型或图像生成服务。此记录不代表已测试其它宿主版本或所有第三方主题。
