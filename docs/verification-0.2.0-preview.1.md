# 0.2.0-preview.1 发布前验收 · 2026-11-02

本文记录发布前的检查。用户个人 desktop profile 的安装回执另存本地，不进入公开仓库。

## 合并与兼容

- 在原 dsh-nai5-prompting 历史上合并稿纸功能，不创建第二个发布仓库。
- 安装身份保持 `dsh-nai5-prompting`，预设 ID 保持 `nai5-prompting`，67 个技能文件及 vendor.json 与 v0.1.6 所含 v1.2.8 快照逐字节一致。
- 全局根入口以 `mode: desk` 启动稿纸服务，使 dsh 能发现同包的客户端；没有该 mode 的旧根入口配置继续执行隔离逻辑，原有配置默认值与导出保留。
- 稿纸工具只挂入 NAI5 预设内部。Connection 通过子作用域按需挂载，没有 Connection 时数据服务仍可启动。
- 安装包带预构建 lib，未设置 install/postinstall/prepare/prepack 等安装构建钩子；无需降低宿主构建安全设置。

## 自动检查

`npm test`：**60 项通过**，包含旧隔离行为、技能字节校验、单包根入口与客户端注册、稿纸会话隔离、字符身份、持久化失败回滚、并发版本冲突、界面未保存文字与迟到响应、认证路由适配、分发边界。

独立只读合并审查检查了包身份、预设作用域、入口兼容与 Connection 生命周期，并运行 25 项相关检查。随后实机发现客户端需要全局根入口挂载，已加入 mode 兼容入口并补充测试，完整套件再次通过。

## 隔离宿主实测

使用桌面端自带 dsh 0.2.1-rc.5、全新临时 DSH_HOME、单个合并包和本机假模型。profile patch 只有假模型设置，没有任何 NAI5 覆盖或单独面板包。

- 普通模式仍有原工具，右栏没有稿纸入口，发给模型的工具列表无 desk_*。
- NAI5 可选，右栏自动出现提示词稿纸；模型通过 desk_read/set_main/set_character/set_uc 写入后，面板立即更新。
- 面板手动改主串、切换 UC 保存后，模型读取到相同文字和换行。
- NAI5 实际请求包含 6 个稿纸工具；根入口调整后再次核对了普通模式隔离。
- 未认证接口请求 401，跨 Origin 请求 403，已认证 NAI5 读取 200。
- 稿纸核心的角色排序、启停、删除撤销、折叠、全栏编辑及宿主重启恢复，已在合并前同版本宿主的隔离环境实测；相应核心逻辑与回归测试保留。

本轮合并实测有 **9 次本机假模型请求**，**0 Anlas、0 外部模型 API 请求**。没有真实生图或真实模型质量评估。

## 本机安装前检查

既有 desktop-kit doctor 检查无阻断项；提示缺少若干可选技能，未为此安装技能、修改补丁或放宽检查。用户已确认完全退出桌面端与 TUI，实际安装前会再次核对进程并备份 profile 配置。

## 已知边界

- 这是预发布版；当前宿主实测范围为 0.2.1-rc.5。
- 自定义 profile 若覆盖完整 NAI5 预设行，需要自行对照新 bundle 合并稿纸工具与交付说明。
- 会话分叉暂不继承原稿纸；强制关闭前应确认手动修改已保存。
- 非网页数据服务有单元覆盖，未把它当作全部 TUI 场景验收。
- 没有骰子、剪贴板脚本、官网填词、OC 查询、块库、MCP 或 W.O.F 连接。
